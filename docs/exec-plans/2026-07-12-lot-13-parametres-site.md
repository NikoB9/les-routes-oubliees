# Lot 13 - Parametres du site

## Objectif

Administrer les parametres transverses du site.

## Perimetre

- Backend admin : lecture et mise a jour du nom du site, sous-titre, logo, fuseau horaire, message de maintenance, etat du site et informations d'accessibilite.
- Frontend admin : formulaire de parametres, etats accessibles, validation.
- Qualite : tests d'integration et frontend.

## Hors perimetre

- Carte.
- Bloc-notes.
- Refonte visuelle globale.

## Criteres de validation

- Les parametres sont modifiables depuis l'administration.
- Les valeurs sont validees cote serveur.
- Les tests pertinents passent.
